# Campus Placement & Recruitment Portal

A Spring Boot & JDBC application for managing student profiles and job postings.

## How to Run in VS Code

1. Extract this ZIP archive and open the project folder in VS Code.
2. Open the integrated terminal (`Ctrl + ~` or `Cmd + ~`).
3. Run:
   ```bash
   mvn spring-boot:run
   ```
4. Open your browser and navigate to `http://localhost:8080`.
